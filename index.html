01 · FOUNDATION

mini-agent

从零写一个 300–800 行的 TS Agent，证明你懂 loop/tool/context，而不是只会调框架。

  • 5 个工具 + Zod + 错误回传

  • subagent / memory / compaction
  • JSONL trace + 失败分类
02 · FLAGSHIP

Agent Workbench

面向 Vue 代码库的 Agent 工作台：review / fix / test / docs，diff 审批、trace、eval。

  • Nuxt + Vue + AI SDK + assistant-ui
  • NestJS + Postgres + Redis + Docker
  • 30 条评测 + 成本/延迟
  • 多租户 / 沙箱 / 红队
03 · OPEN SOURCE

Vue MCP + Skill
