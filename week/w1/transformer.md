+ Transformer 采用 Encoder-Decoder架构
    - Encoder 用于编码输入序列
    - Decoder 用于解码输出序列
+ 自注意力机制 self-attention 是transformer 中的核心机制
    解决了模型如何将上下文理解融入到当前处理的词中

+ Q, K, V 分别表示查询、键、值
    - 查询：当前处理的词
    - 键：输入序列中的所有词
    - 值：输入序列中的所有词
    每个词的嵌入向量（Embedding，维度为 512）会分别乘以三个训练得到的权重矩阵 $W^Q$、$W^K$、$W^V$，投影生成对应的 Query（查询 $q$）、Key（键 $k$） 和 Value（值 $v$） 向量（维度通常压缩为 64）。
+ 计算步骤
    - 计算得分：用当前词的 Query 向量与所有词的 Key 向量做点积（如 $q_1 \cdot k_1$）。
    - 缩放：将得分除以键向量维度的平方根（$\sqrt{64} = 8$），使梯度更加稳定。
    - Softmax：通过 Softmax 归一化得分，使其全部为正且加和为 1。
    - 加权：将归一化后的分数与各自的 Value 向量相乘，保留需要关注的词的特征，弱化不相关的词。
    - 求和：将加权后的 Value 向量求和，得到该位置自注意力层的最终输出。

+ 多头自注意力机制 Multi-Head Attention
    - 优势：
        - 扩展焦点：允许模型关注不同位置的不同信息。
        - 多重子空间表示：模型维护多组不同的 $Q$、$K$、$V$ 权重矩阵（例如 8 个头），从而在多个不同的表示子空间中捕捉特征。
        - 矩阵拼接：多头计算出的多个矩阵会拼接（Concat）起来，再乘以一个额外的权重矩阵 $W^O$ 压缩回单矩阵输入给下一层。


+ tokenizer 分词器 BPE 字节对编码
    + 为什么中文分词比英文长？
        - BPE高频优先原则，模型常见的训练资源多为英文，在英文语料中，the,and,it等常见的高频词，会优先合并成1个token。
         而中文语料中，在整个训练池占比较小，无法被合并成词表，因次只能被退回更基础的字节，一个汉字在UTF-8编码中大概占3个字节。
         如果没有没有被合并成1个token，就会被拆分成2-3个字节级的token
         
    + 为什么相同参数，不同模型的长度不同？
        - 不同模型搭载了不同的分词器，它们在“训练语料”、“词表大小”和“预处理规则”上存在差异。
           - 词表大小悬殊：GPT-2的词表约为5万，而 o200k_base 的词表高达20万。更大的词表意味着有更多“名额”来收录各种语言（包括中文）的常见组合。

           - 训练语料分布不同：GPT-2的训练语料以英文为绝对主导。而 o200k_base 的训练数据更加多元，明确包含了大量多语言内容，并针对性地加入了常见的中日韩词组。

           - 预处理规则（Pre-tokenization）演进：在切分成子词之前，文本会先经过一轮规则切分。o200k_base 的切分规则（例如基于Unicode属性）比GPT-2更精细，能更智能地处理大小写、数字和不同文字系统。
